# MATHJOY

Crie um aplicativo web/mobile gamificado chamado “MathJoy” focado em aprendizagem divertida de matemática para estudantes do ensino fundamental e médio.

O app deve possuir visual extremamente moderno, vibrante e envolvente, inspirado em jogos educacionais premium, com muitas animações fluidas, partículas, transições suaves, efeitos sonoros satisfatórios e feedback visual constante.

OBJETIVO DO APP:
Transformar exercícios matemáticos em desafios interativos e emocionantes, estimulando lógica, interpretação de problemas e resolução rápida.

PALETA DE CORES:

Verde neon/sustentável

Branco

Interface clean com glow effects e iluminação dinâmica

ESTILO VISUAL:
